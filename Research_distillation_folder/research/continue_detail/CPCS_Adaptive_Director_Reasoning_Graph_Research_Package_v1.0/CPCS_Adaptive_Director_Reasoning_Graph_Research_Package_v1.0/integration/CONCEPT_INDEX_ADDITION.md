# Proposed CONCEPT_INDEX Addition: Part ADRG — Adaptive Director Reasoning Graph

## ADRG-1. Reasoning is a separate control plane

The scene score says what the shot should do. The reasoning graph says how a planner retrieves, decomposes, branches, selects, compiles, and verifies that score. Store auditable decision records, not raw private chain-of-thought transcripts. Source: ADRG §§1, 4–6.

Cards: `c_reasoning_control_plane`, `c_adaptive_director_reasoning_graph`, `c_decision_ledger`, `c_five_graph_planes`.

## ADRG-2. Route reasoning by decision value and model capability

Use direct compile+validate for low-complexity nodes; fixed least-to-most for routine decomposition; selective ToT for high-impact independent alternatives; GoT subgraphs for coupled departments; ReAct for retrieval/tools; and code for deterministic computation. Mini models receive fixed narrow graphs and strict schemas. Source: ADRG §§3, 9–10.

Cards: `c_model_scaled_reasoning_policy`, `c_reasoning_router`, `c_schema_constrained_specialists`, `c_teacher_student_decision_distillation`.

## ADRG-3. Variants are invariant-preserving semantic deltas

Declare protected invariants, typed axes, allowed values, incompatibilities, and maximum simultaneous deltas. Measure diversity by compiled control differences, not wording. Use one-lever A/B tests for causal promotion. Source: ADRG §11 and §21.

Cards: `c_selective_branch_admission`, `c_variant_lattice`, `c_reasoning_mode_ablation`.

## ADRG-4. RAG returns a compatible bundle and a coverage report

Decompose a request into department queries; retrieve concept, evidence, template, failure, compiler, model-policy, and variant objects; expand only typed edges; include conflicts; rerank for provenance and target capability. Source: ADRG §12.

Cards: `c_graph_aware_rag_bundle`.

## ADRG-5. One ontology, several carriers

Natural language owns intent and observable behavior; YAML owns authoring and reasoning policy; JSON owns canonical graphs, patches, and exact data; XML owns ordered mixed narrative and namespaced events; JSONL owns append-only evidence. One authoritative source per semantic path. Source: ADRG §§13–17.

Cards: `c_semantic_format_ownership`, `c_compile_loss_ledger`.

## ADRG-6. External validation is the promotion gate

Separate authoring, compiler, and verifier roles. Validate parsing, schemas, references, graph integrity, temporal semantics, authority, capability, loss budget, package hashes, and rendered evidence. Source: ADRG §19.

Cards: `c_external_validation_over_self_critique`, `c_compile_loss_ledger`, `c_reasoning_mode_ablation`.
