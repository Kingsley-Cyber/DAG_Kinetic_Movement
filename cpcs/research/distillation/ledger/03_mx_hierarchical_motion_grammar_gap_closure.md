## PASS 5 — Representation/compiler findings

- **Carrier roles**: SRC-003 extends existing carrier owner (E12) with 16
  non-text carriers (reference image, identity reference, first/last frame,
  pose, skeleton, depth, mask, trajectory, control video, reference video,
  audio timing, postproduction). Carrier selection is a semantic decision, not
  prose-default.
- **Attention budget**: canonical motion graph → locked constraints → salience
  → observability → provider capability → reliability → redundancy collapse →
  token budget → minimal sufficient carrier. This is semantic prioritization,
  not merely token optimization.
- **Text-format vs carrier experiment**: the previous five-format test should be
  split into semantic representation test (YAML/JSON/XML/NL) and control-carrier
  test (NL/reference image/pose/control video/first-last frame).
- **Temporal precision**: exact_timestamp / approximate_timestamp / relative_phase
  / sequence_only / unsupported — compile according to empirical provider behavior.
- **Evidence taxonomy orthogonality**: four dimensions, not one enum (knowledge
  basis × acquisition/derivation × epistemic state × confidence).
- **P0 implementation order**: P0-A (shared contracts) → P0-B (MX grammar) →
  P0-C (compilation) → P0-D (verification).
