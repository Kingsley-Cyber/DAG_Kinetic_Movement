# SRC-003 Open Research Questions

SRC-003 §52 identifies ten research questions that remain genuinely empirical.
None should be filled with invented constants. Each should have a fixture and
measurable outcome before becoming a hard CPCS rule.

1. Which primitive decompositions produce the most consistent provider motion?
2. Which action-conditioned realization features actually improve video adherence?
3. What contact-distance/velocity thresholds distinguish convincing contact from
   near-contact for each media regime?
4. Which support metrics correlate with perceived physical grounding?
5. Which carriers best preserve trajectory versus identity versus interaction?
6. What control density causes provider degradation?
7. When does shot decomposition improve results versus reduce continuity?
8. Which semantic redundancy rules improve adherence?
9. What retargeting errors are perceptually acceptable?
10. What provider-specific temporal precision is real rather than nominal?

## Governance note

- These questions overlap with the SRC-003 fixtures (§50) which provide 20 test
  cases designed to exercise these empirical boundaries.
- Q5/Q6 are operationalized by the carrier-effect experiments (SRC-001).
- Q7 relates to the shot-decomposition risk profile (cpcs.mx.risk_profile).
- Q3 relates to verification expectation thresholds (cpcs.verification.verification_expectation_model).
- All thresholds remain `experimental` / `null` until calibrated.
